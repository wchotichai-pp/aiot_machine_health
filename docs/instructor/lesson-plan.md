**กลุ่มเป้าหมาย:** ช่างซ่อมบำรุง วิศวกรโรงงาน หัวหน้าไลน์ผลิต ไม่จำเป็นต้องเขียนโปรแกรมเป็น (บทที่ 8 ข้อ 4 สำหรับผู้ที่เขียนได้)
**ขนาดชั้น:** 10–20 คน · **เวลา:** ประมาณ 3 ชั่วโมง

## เตรียมก่อนสอน

- [ ] PC ผู้สอน RAM 16 GB ติดตั้ง Docker Desktop และรัน `docker compose up -d --build` จนโมเดลดาวน์โหลดเสร็จ (ทำล่วงหน้า เพราะใช้อินเทอร์เน็ตมาก)
- [ ] เราเตอร์ WiFi 2.4 GHz ของห้องเอง ปิด client isolation และจด IP ของ PC ผู้สอน
- [ ] แฟลชเฟิร์มแวร์ให้ทุกบอร์ดล่วงหน้า แต่ละบอร์ดใช้ `DEVICE_ID` ไม่ซ้ำ เช่น `fan-01` ถึง `fan-20` และติดป้ายชื่อบนบอร์ด
- [ ] พัดลมตั้งโต๊ะที่มีตะแกรง 1 ตัวต่อกลุ่ม เทปกาวสองหน้า เคเบิลไทร์ เทปกาวสำหรับถ่วงใบพัด
- [ ] สร้างบอทของห้องหนึ่งตัว และเปิด Dev Tunnel พอร์ต 8000 แบบ Public
- [ ] ทดสอบ: รันตัวจำลอง `--demo` แล้วตรวจว่าแจ้งเตือนเข้า Telegram

!!! tip "บอทกลุ่มเดียวกันทั้งห้อง"
    ในห้องเรียนจริงให้เว้น `ALLOWED_USER_IDS` ว่างระหว่างคาบ แล้วตั้งค่าทันทีหลังจบคาบ
    หรือให้ผู้เรียนพิมพ์ `/start` แล้วรวบรวม user id ใส่ก่อนเริ่มบทที่ 6
