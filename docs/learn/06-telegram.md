# 6. ใช้งานผ่าน Telegram

**เป้าหมายของบท:** สร้างบอท ให้ระบบส่งแจ้งเตือนเข้าแชท สั่งงานด้วยภาษาพูด และเปิดแดชบอร์ดเป็น Telegram Mini App

## 1. สร้างบอทกับ @BotFather

1. ใน Telegram ค้นหา **@BotFather** แล้วพิมพ์ `/newbot`
2. ตั้งชื่อที่แสดง และ username ที่ลงท้ายด้วย `bot`
3. คัดลอก **token** ที่ได้ไปใส่ใน `.env`

```ini
TELEGRAM_TOKEN=123456789:AA...
```

!!! danger "token เหมือนรหัสผ่านของบอท"
    ห้ามใส่ในโค้ด ห้ามถ่ายหน้าจอที่เห็น token ถ้าหลุดให้สั่ง `/revoke` ใน @BotFather เพื่อออก token ใหม่

## 2. ทำ port forwarding ไป Microsoft Dev Tunnels

Telegram เปิด Mini App ได้เฉพาะเว็บแบบ **HTTPS** แต่แดชบอร์ดอยู่ที่ `http://localhost:8000` จึงต้องสร้าง tunnel

1. ใน VS Code เปิดแท็บ **PORTS** (ข้าง TERMINAL)
2. กด **Forward a Port** แล้วใส่ `8000`
3. ล็อกอินด้วย GitHub หรือ Microsoft
4. คลิกขวาที่พอร์ต 8000 → **Port Visibility → Public**
5. คัดลอก URL เช่น `https://abcd1234-8000.asse.devtunnels.ms` ไปใส่ใน `.env`

```ini
MINIAPP_URL=https://abcd1234-8000.asse.devtunnels.ms
```

!!! info "Public แล้วใครก็เข้าได้ไหม"
    เข้าหน้าเว็บได้ แต่**ดูข้อมูลไม่ได้** gateway ตรวจลายเซ็นที่ Telegram แนบมากับทุกคำขอ (`initData`)
    และตรวจรายชื่อผู้ใช้ใน `ALLOWED_USER_IDS` ดูรายละเอียดใน[ความปลอดภัย](../instructor/security.md)

## 3. เปิดบอทและกำหนดสิทธิ์

```bash
docker compose up -d
```

`up -d` จะสร้าง container ที่ค่าใน `.env` เปลี่ยนใหม่ให้เอง

1. เปิดแชทกับบอท แล้วพิมพ์ `/start` บอทจะตอบพร้อมบอก **user id** ของคุณ
2. ตอนนี้ `ALLOWED_USER_IDS` ยังว่าง ใครที่หาบอทเจอก็สั่งงานได้ ให้ใส่ user id ของคุณใน `.env`
   แล้วรัน `docker compose up -d` อีกครั้ง หลังจากนี้คนที่ไม่อยู่ในรายชื่อจะได้รับข้อความว่าไม่มีสิทธิ์

```ini
ALLOWED_USER_IDS=123456789
```

3. พิมพ์ `/start` อีกครั้ง จะเห็นปุ่ม **📈 เปิดแดชบอร์ด** และปุ่ม **Dashboard** ข้างช่องพิมพ์

## 4. คุยกับระบบ

| ลองพิมพ์ | ระบบทำอะไร |
| --- | --- |
| เครื่องเป็นยังไงบ้าง | รายงานสถานะ ค่าการสั่น อุณหภูมิ และเกณฑ์ |
| เรียนรู้ค่าปกติใหม่ | เริ่มเก็บค่าปกติ 30 วินาที |
| จะเปลี่ยนลูกปืน ปิดแจ้งเตือน 1 ชั่วโมง | เข้าโหมดซ่อมบำรุง 60 นาที |
| ซ่อมเสร็จแล้ว | กลับมาเฝ้าระวัง |
| แจ้งเตือนช้าไป ให้ไวขึ้นหน่อย | ปรับความไวเป็น "สูง" |
| อย่าเพิ่งเรียนรู้ค่าปกตินะ | ไม่ทำอะไร (ประโยคปฏิเสธ) |
| ช่วยด้วย | แสดงคำสั่งทั้งหมด |

ท้ายคำตอบทุกครั้งจะบอกว่า**ใครเป็นคนแปล**และได้คำสั่งอะไร เช่น

```text
— แปลโดย 🤖 AI: maintenance minutes=60
```

ถ้าเห็น `📏 กฎ (AI ไม่ตอบ)` แปลว่า AI ตอบช้าหรือตอบผิดรูปแบบ ระบบจึงใช้ตัวแปลด้วยกฎคำสำคัญแทน
ถ้าเห็น `📏 กฎ (AI ไม่เข้าใจ)` แปลว่า AI ตอบว่า "ไม่มีคำสั่ง" แต่ตัวแปลด้วยกฎเจอคำสั่งที่ชัดเจน ระบบจึงใช้ของกฎ

## 5. รับแจ้งเตือน

ทุกแชทที่พิมพ์ `/start` จะได้รับข้อความเมื่อ

- สถานะเปลี่ยน เช่น 🔴 ปกติ → อันตราย พร้อมเหตุผลและตัวเลข
- เรียนรู้ค่าปกติเสร็จ
- บอร์ดหลุดหรือกลับมาเชื่อมต่อ

พิมพ์ `/stop` เพื่อหยุดรับแจ้งเตือนในแชทนั้น ลองรันตัวจำลองแบบ `--demo` แล้วดูข้อความที่เข้ามา

## 6. แดชบอร์ดใน Telegram

กดปุ่ม **Dashboard** จะเห็นหน้าเดียวกับบทที่ 4 แต่ปรับสีตามธีม Telegram ทักทายด้วยชื่อคุณ
ถามยืนยันก่อนสั่งงานด้วยหน้าต่างของ Telegram (`showConfirm`) และมือถือสั่นเบา ๆ เมื่อสั่งสำเร็จ (`HapticFeedback`)

!!! tip "URL ของ tunnel เปลี่ยน"
    ถ้าปิด VS Code หรือ forward พอร์ตใหม่ URL อาจเปลี่ยน ให้แก้ `MINIAPP_URL` แล้วรัน `docker compose up -d`
