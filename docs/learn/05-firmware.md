# 5. ติดตั้งบอร์ด Cucumber

**เป้าหมายของบท:** อัปโหลดเฟิร์มแวร์ ติดบอร์ดบนเครื่องจักร และเห็นข้อมูลจริงในแดชบอร์ด

!!! note "ยังไม่มีบอร์ด"
    ข้ามบทนี้ได้ ตัวจำลองในบทที่ 4 ส่งข้อมูลแบบเดียวกันทุกประการ

## 1. เปิดโปรเจกต์เฟิร์มแวร์

ใน VS Code เลือก **File → Open Folder** แล้วเปิดโฟลเดอร์ `firmware/cucumber_vibration`
PlatformIO จะอ่าน `platformio.ini` และดาวน์โหลดไลบรารีให้เอง

| ไลบรารี | ใช้ทำอะไร |
| --- | --- |
| Adafruit MPU6050 | อ่านความเร่ง |
| Adafruit HTS221 | อ่านอุณหภูมิ/ความชื้น |
| Adafruit NeoPixel | คุมไฟ RGB ที่ GPIO18 |
| PubSubClient | MQTT |
| ArduinoJson | สร้าง/ตรวจ JSON |

## 2. ตั้งค่า WiFi และ MQTT

คัดลอก `include/secrets.h.example` เป็น `include/secrets.h` แล้วแก้ค่า

```cpp
#define WIFI_SSID     "ชื่อ WiFi 2.4 GHz"
#define WIFI_PASS     "รหัส WiFi"
#define MQTT_HOST     "192.168.1.10"   // IP ของ PC ที่รัน docker compose
#define MQTT_PORT     1883
#define DEVICE_ID     "pump-01"        // ตัวพิมพ์เล็ก a-z 0-9 - _ ไม่ซ้ำกันในห้อง
```

!!! danger "secrets.h มีรหัส WiFi"
    ไฟล์นี้อยู่ใน `.gitignore` แล้ว อย่า commit ขึ้น GitHub

## 3. อัปโหลดและดู Serial Monitor

1. เสียบสาย USB ที่พอร์ต **Debug** ของบอร์ด (พอร์ตที่มีชิป USB-to-UART)
2. กด **Upload** (ลูกศร →) ที่แถบล่างของ VS Code
3. กด **Serial Monitor** (รูปปลั๊ก) ความเร็ว 115200

ผลที่ควรเห็น

```text
MPU-6050 OK, HTS221 OK
WiFi -> MyWiFi
WiFi connected, IP 192.168.1.37, RSSI -55
MQTT -> 192.168.1.10:1883 ... connected
-> seq=0 rms=0.071 peak=0.214 sent
<- normal (green) การสั่น 0.07 m/s² ต่ำกว่าเกณฑ์เฝ้าระวัง 1.00
```

บรรทัด `->` คือบอร์ดส่งข้อมูล บรรทัด `<-` คือคำสั่งที่ gateway ตอบกลับ ไฟบนบอร์ดจะเปลี่ยนตามบรรทัด `<-`

## 4. ติดบอร์ดบนเครื่องจักร

- ติดให้**แน่น** ใช้เทปกาวสองหน้าแบบโฟมบางหรือเคเบิลไทร์ บอร์ดที่โยกได้เองจะวัดการสั่นของบอร์ด ไม่ใช่ของเครื่อง
- ติดใกล้จุดรับแรง เช่น ตัวเรือนมอเตอร์ใกล้ลูกปืน ไม่ใช่ฝาครอบพลาสติก
- ติดตำแหน่งเดิมทุกครั้ง ถ้าย้ายตำแหน่งต้องเรียนรู้ค่าปกติใหม่
- เดินสาย USB ให้ห่างจากชิ้นส่วนที่หมุน

!!! warning "ความปลอดภัยหน้างาน"
    ทดลองกับเครื่องเล็กที่ไม่มีอันตราย เช่น พัดลมตั้งโต๊ะที่มีตะแกรงครอบ
    กับเครื่องจักรจริงต้องทำตามขั้นตอนความปลอดภัยของโรงงาน (เช่น Lockout/Tagout) ก่อนเข้าใกล้ชิ้นส่วนที่หมุน

## 5. ทดลองกับพัดลมตั้งโต๊ะ

1. เปิดพัดลมเบอร์ 1 แล้วสั่ง "เรียนรู้ค่าปกติ" จากแดชบอร์ด
2. ติดเทปกาวก้อนเล็ก ๆ ที่ปลายใบพัดหนึ่งใบเพื่อให้**เสียสมดุล** (ปิดพัดลมก่อนทุกครั้ง)
3. เปิดใหม่ ดูว่าค่า RMS เพิ่มขึ้นกี่เท่า และสถานะเปลี่ยนหรือไม่
4. ลองเปิดเบอร์ 3 โดยไม่ติดเทป สถานะเปลี่ยนไหม เพราะอะไร

## กฎสำรองในบอร์ด

ถ้าไม่ได้รับคำตอบจาก gateway เกิน 10 วินาที บอร์ดตัดสินเองแบบง่าย ๆ

- <span class="state-dot purple"></span>ม่วงค้าง = ออฟไลน์ แต่การสั่นยังต่ำ
- <span class="state-dot red"></span>แดงกะพริบ = ออฟไลน์ และการสั่นเกิน 2.5 m/s²

เมื่อเชื่อมต่อได้อีกครั้ง บอร์ดจะกลับไปใช้สีจาก gateway ทันที
